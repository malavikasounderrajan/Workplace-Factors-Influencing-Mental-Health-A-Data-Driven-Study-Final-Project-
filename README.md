**# Workplace-Factors-Influencing-Mental-Health-A-Data-Driven-Study-Final-Project-**

Python + Power BI project analyzing employee mental health trends, treatment behaviour, and workplace support factors through interactive dashboards.

#**Project Overview**

This project focuses on analyzing employee mental health trends and treatment behavior using workplace survey data. The aim is to identify key factors affecting mental health in organizations and provide actionable insights through data analytics and visualization.The project uses Python for data preprocessing and exploratory data analysis (EDA), and Power BI for creating an interactive dashboard that highlights workplace mental health patterns.

#**Objectives**

Identify meaningful patterns and trends related to employee mental health.
Clean and preprocess messy raw data for analysis.
Perform exploratory data analysis (EDA) using visualizations.
Build an interactive Power BI dashboard.
Generate actionable business insights and recommendations.

#**Dataset Information**

Source: OpenML Dataset (ID: 46865)
Domain: Workplace Mental Health
Records: 1200+ employee survey responses
Features: Demographics, workplace conditions, mental health treatment, benefits, wellness programs, remote work, family history, etc.

**Data Preprocessing**

The dataset contained missing values, inconsistent categorical values, duplicates, and mixed data types. The following preprocessing steps were performed:

Removed duplicate rows
Handled missing values using mode/Unknown categories
Converted Age column to numeric
Standardized inconsistent Gender values
Dropped irrelevant columns like comments
Checked null values and inconsistencies

**Key Insights**

1. High Treatment Rate

A significant number of employees have sought mental health treatment, indicating increasing awareness and mental health concerns.

2. Work Interference Impacts Employees

Employees whose mental health interferes with work are more likely to seek treatment.

3. Family History Matters

Employees with a family history of mental illness show higher treatment rates.

4. Benefits Encourage Support

Organizations providing mental health benefits and wellness programs encourage employees to seek help.

5. Remote

Remote work shows a noticeable relationship with employee mental well-being and treatment behavior.

**Business Recommendations**

This project demonstrates how data analytics and visualization can help organizations understand employee mental health challenges and improve workplace support systems. The insights generated can assist businesses in making informed decisions that enhance employee well-being and productivity.
